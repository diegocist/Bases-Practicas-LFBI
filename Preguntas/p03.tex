\addcontentsline{toc}{subsection}{Pregunta 3}
\textbf{¿Por qué una empresa debería escoger una base de datos open source?}\\ \\
Siempre que no se tengan requerimientos de muy alta disponibilidad, el usar una base de datos open source evita los costos de licenciamiento, así se reduce el gasto inicial permitiendo a la empresa invertir el dinero en un mejor diseño e implementación de la base de datos.
