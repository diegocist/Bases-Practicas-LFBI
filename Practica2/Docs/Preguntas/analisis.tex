\subsection*{2. Comprensión del contexto del sistema}
\addcontentsline{toc}{subsection}{2. Comprensión del contexto del sistema}

\begin{enumerate}
    \item Un cliente posee una única tarjeta registrada bajo su identidad.
    \item Una tarjeta puede recibir varias recargas.
    \item Una sucursal tiene varias máquinas.
    \item Una máquina tiene un único juego.
    \item Una máquina pertenece exclusivamente a una sucursal.
    \item Una máquina puede registrar varias partidas, cada una con una única tarjeta registrada.
    \item Un juego puede instalarse en multiples maquinas de diferentes sucursales.
    \item Una sucursal puede tener varios premios en su inventario.
    \item Un cliente puede usar su tarjeta para realizar canjes por varios premios en diferentes sucursales.
    \item Una sucursal emplea a multiples empleados, pero cada empleado esta registrado en una unica sucursal.
    \item Un gerente administra una única sucursal.
    \item Un cajero puede vender varias tarjetas.
    \item Un cajero puede efectuar múltiples recargas.
    \item Un encargado procesa varios canjes, y otorga varios premios.
    \item Un técnico realiza mantenimiento a varias máquinas, si están averiadas.
    \item Una maquina puede recibir multiples servicios de mantenimiento en el tiempo.
\end{enumerate}

\subsection*{4. Captura de requerimientos no funcionales.}
\addcontentsline{toc}{subsection}{4. Captura de requerimientos no funcionales.}

\subsubsection*{Asociados a requerimientos funcionales.}
\addcontentsline{toc}{subsubsection}{Asociados a requerimientos funcionales.}

\begin{enumerate}
    \item Cada cliente puede tener únicamente una tarjeta activa.
    \item Las máquinas son exclusivas de cada sucursal
    \item Los juegos de destreza y disparos pueden otorgar únicamente 1 punto por cada acierto, mientras que los juegos de velocidad y ritmo otorgan 20 puntos únicamente si se queda dentro de los primeros 5 lugares
    \item Un juego puede existir en múltiples sucursales
    \item El costo de los juegos y las recargas a las tarjetas solo se pueden ser múltiplos de 10.
    \item Un cliente registra una visita si emplea su tarjeta en cualquier sucursal por primera vez en un día.
\item Un cliente puede obtener el rango VIP si asiste al menos 10 veces en un mes, pero dicho rango solo se conserva durante el siguiente mes.
\item Un cliente con rango VIP recibe el 10\% adicional de puntos obtenidos por partida.
\item Un cliente no puede recibir un premio por encima de su rango de edad.
\item Un cliente solo puede realizar un canje si su acumulación de puntos es suficiente.
\item El costo de puntos de un premio debe rondar el doble de su precio de adquisición.
\item La tarjeta debe reducir el puntaje invertido en cada canje realizado.
\end{enumerate}

\subsubsection*{No asociados a requerimientos funcionales.}
\addcontentsline{toc}{subsubsection}{No asociados a requerimientos funcionales.}

\begin{enumerate}
    \item Suficiente almacenamiento en el sistema.
    \item Proteger la privacidad de los empleados y de los usuarios.
    \item Escalabilidad.
\end{enumerate}
